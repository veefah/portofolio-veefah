About

Sejak lama, saya tertarik pada bidang teknologi informasi, meskipun dahulu saya merasa bidang ini sulit untuk saya capai. Perjalanan saya mulai berkembang ketika mendapat kesempatan mengikuti program IDCamp 2025 melalui alur belajar AI Front-End Developer yang mengharuskan saya menyelesaikan tiga kelas yaitu : Belajar Dasar Pemrograman Web, Belajar Dasar Pemrograman JavaScript,Belajar Membuat Front-End Web untuk Pemula. Saat itu, saya masih sangat awam dengan pemrograman, memahami istilah, konsep, dan alur pembelajarannya membutuhkan banyak usaha, tetapi pengalaman tersebut justru membuat saya semakin ingin mendalami web development.

Melalui program tersebut, saya berhasil menyelesaikan tiga kelas pembelajaran. Meskipun belum berhasil memenuhi tenggat untuk memperoleh beasiswa lanjutan, saya tetap bersyukur dapat menuntaskan materi yang tersedia. Setelah itu, saya memilih untuk berfokus memperkuat pemahaman dan berlatih HTML serta CSS melalui latihan mandiri.

Salah satu bentuk latihan tersebut adalah mengembangkan Anime Info Hub, sebuah proyek yang menjadi jejak perjalanan belajar saya dalam menerapkan HTML dan CSS secara bertahap. Melalui proyek ini, saya mencoba menerapkan materi yang dipelajari, mengeksplorasi berbagai teknik layout, serta belajar memahami penyebab masalah pada kode dan mencari cara untuk memperbaikinya. Bagi saya, proses mencoba, memahami, dan memperbaiki kesalahan merupakan bagian penting dari perjalanan belajar.

Ke depannya, saya ingin terus memperkuat fondasi Front-End Development sebelum mendalami JavaScript lebih lanjut. Saya juga ingin mendapatkan pengalaman melalui kesempatan magang, belajar dari tim yang berpengalaman, dan berkontribusi dalam proyek nyata sebagai langkah menuju karier profesional di bidang ini.

Point Pembelajaran

Poin Pembelajaran

  • Menyusun gambar dan informasi produk dalam layout menggunakan Flexbox.

  • Menjaga gambar dan informasi produk tersusun rapi dalam satu card.
  • Menyesuaikan layout agar mendekati desain referensi pada kedua tampilan.
